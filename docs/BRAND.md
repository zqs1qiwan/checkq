# CheckQ 品牌指南

> 本文件定义品牌名称、标志、色彩、界面用法与资产路径；`docs/UI-STANDARDS.md` 负责组件与交互细节。
> 资产源文件在 `web/public/brand/`，构建时随前端产物原样发布。

---

## 1. 品牌是什么

**名称**：CheckQ（`Check` + 大写 `Q`，中间不留空格）

**一句话**：开源的可视化自动挂机、签到框架。

**产品定位**：给会用浏览器、但不想写脚本的人，一个把重复 HTTP 操作变成可编辑、可复用、可被外部程序驱动的定时工作台。

**三条承诺**：看得见 · 说得清 · 拿得走。

**语气**：克制、清楚、可执行。少用形容词，多给状态、原因和下一步。

## 2. 标志

### 2.1 构成

标志是一枚**深青圆角方标**，内部是**白色勾**与右下角的**浅青 Q 尾点**：

- 勾 = 完成、可核对；
- 圆角方 = 可托付的容器；
- 右下点 = Q 的尾巴，也是「一次任务、一个结果」的落点。

图形不依赖文字，16px 仍能读出「勾 + 点」；完整品牌名由字标 `CheckQ` 承担，字标中的 `Q` 使用强调色。

### 2.2 色彩

| 角色 | 值 | 用法 |
|---|---|---|
| 标志底 | `#0e5a63` | 徽章底色，深浅主题共用 |
| 勾 | `#ffffff` | 主图形 |
| Q 尾点 | `#a7e7e9` | 唯一强调点，不扩大使用 |
| 界面强调 | `--accent` | 字标 Q、主按钮、焦点与选中态（由主题令牌决定） |

标准标志是**平涂**，不使用渐变、阴影、发光或描边。单色场景使用 `checkq-mark-mono.svg`（黑底白形），反白场景直接把彩色徽章放在深色底上。

### 2.3 组合与留白

- 横向组合：徽章 + 8px 间距 + 字标，共享视觉中线。
- 徽章外留白不小于徽章边长的 **1/2**，不要用文字或边框贴住。
- 最小数字尺寸 **16px**；界面常用 22px（顶栏）、30px（加载）、38px（空状态）、44px（登录页）。
- 不拉伸、不旋转、不改变圆角比例；不把勾替换成其它图标，不把尾点移到左上。

### 2.4 资产

| 文件 | 用途 |
|---|---|
| `web/public/brand/checkq-mark.svg` | 标准彩色标志（矢量，优先使用） |
| `web/public/brand/checkq-mark-mono.svg` | 单色/印刷用标志 |
| `web/public/favicon.ico` | 浏览器标签页兜底（16/32/48/64） |
| `web/public/favicon-16x16.png` / `favicon-32x32.png` | 位图 favicon |
| `web/public/apple-touch-icon.png` | iOS / Safari 主屏图标 180×180 |
| `docs/assets/social-preview.png` | GitHub 仓库社交预览 1280×640（仓库 Settings → Social preview 上传） |

网页 `head` 中的引用顺序：`favicon.ico` → SVG → 32/16 PNG → `apple-touch-icon`。修改图形时先改 SVG，再按同一几何导出位图，避免两套形状。

## 3. 界面用法

- **首页顶栏**：22px 徽章 + 15px 字标；窄屏只保留品牌、新建、更多、设置四个等高控件。
- **登录页**：左侧品牌区 44px 徽章 + 26px 字标 + 一句话价值主张 + 三条承诺；右侧登录卡。≤820px 折叠为单列，保留品牌与表单。
- **加载态**：30px 徽章 + 字标 + “正在加载…”，不使用裸文字占位。
- **空状态**：38px 徽章作为低对比度水印，下方一句可执行说明；搜索无结果时不显示徽章。
- **文档站 / GitHub**：使用 `web/public/brand/checkq-mark.svg`，标题只用文字 `CheckQ`；不在同一屏重复堆叠多个标志。

## 5. 不要做

- 不要把标志改成渐变球、发光描边或 3D 徽章。
- 不要为了“科技感”加电路纹理、网格或大量装饰。
- 不要在登录页堆功能清单、版本号或营销口号。
- 不要给字标换字体、加斜体或把 `Q` 做成图片。
- 不要把 favicon 做成与主标不同的图形。
