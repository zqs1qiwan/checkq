# CheckQ 版本历史

> **本文件只记录已经发生的事**：里程碑、交付内容、已关闭的历史遗留。
> **下一阶段的产品规划不在本文件**，见 `docs/PRD.md` §9（Now / Next / Later 与重排触发器）。

---

## 0. 版本口径（先把双轨说清楚）

历史上存在两套说法：代码 `package.json` 从 `0.3.x` 递增，而文档按**产品里程碑**（v0.4）叙述，于是出现"文档说 v0.4、代码是 0.3.17"的双轨。

- 本文用**里程碑（M1–M6）**记录功能演进，避免与代码版本纠缠；
- 代码版本以根 / `server` / `web` 三处 `package.json` 为准（`server/src/version.js` 单源读取）；
- v0.5 起统一为单轨语义化版本，发布时三处同步修改。

---

## 1. 里程碑

| 里程碑 | 主题 | 主要内容 |
|---|---|---|
| M1 | 引擎骨架 | 单链流程执行、`http` / `log` / `set` 节点、变量渲染、cron 调度、基础页面 |
| M2 | 请求控制 | 断言、提取（JSON / 正则 / 头 / Set-Cookie）、延迟与随机延迟、节点级重试、charset 转码、代理、cURL 导入 |
| M3 | 编排能力 | 条件分支、run 级 cookie 罐、模板与派生任务、脚本沙箱、遍历、HAR 导入、QD 模板兼容、日志三档、12 种通知渠道、任务分组 |
| M4 | 产品完整度 | 多用户与角色、TOTP 两步验证、会话管理、凭据静态加密、备份与恢复、使用引导、MCP 工具集、OpenAPI、文档站 |
| M5 | 交互与可靠性 | 任务级退避重试、模板实时跟随、原生 `<dialog>` / Popover、窄屏四控件、双主题重做、编辑器效率能力、五个机械护栏 + 全量验收执行器 |
| M6 | 工程化 | CI、前后端共享纯模块、端口口径定版、版本一致性检查、仓库内容政策 |
