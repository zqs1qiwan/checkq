# 模板索引与导入协议

> **范围**：约定"模板长什么样、索引长什么样、怎么校验、导入后发生什么"。
> **不做**：框架不托管内容、不内置业务模板、不提供官方仓库（产品决定见 `docs/PRD.md` §10.3 D4）。
> **现状**：单模板 URL 导入已实现（`POST /api/templates/from-url`）；索引列表、预览、哈希校验与订阅属于 P0-5（`docs/PRD.md` §5.5），本文件同时承担其规范。

---

## 1. 两种对象

| 对象 | 是什么 | 由谁托管 |
|---|---|---|
| 模板文件（template.json） | 一条流程：节点、连线、默认变量、日志配置 | 任何静态地址（Gist / 仓库 raw / 对象存储） |
| 索引文件（index.json） | 一组模板的清单：元信息 + 变量声明 + 哈希 + 模板地址 | 同上，通常是社区维护的一个文件 |

原则：**索引里可以带完整模板，也可以只带地址**。带完整模板便于离线分发，只带地址便于内容更新；两种都合法。

---

## 2. 模板文件（当前已支持的格式）

```json
{
  "name": "示例模板",
  "desc": "一句话说明它做什么",
  "vars": { "cookie": "", "ua": "Mozilla/5.0" },
  "nodes": [
    { "id": "n0", "type": "http", "name": "请求", "x": 0, "y": 0, "config": {} },
    { "id": "n1", "type": "log", "name": "日志", "x": 0, "y": 120, "config": {} }
  ],
  "edges": [ { "id": "e0", "source": "n0", "sourceHandle": "success", "target": "n1" } ],
  "log": { "level": "all", "keywords": [] }
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | ✅ | 模板名（界面展示，导入后可改） |
| `desc` | — | 一句话说明 |
| `vars` | — | 默认变量；敏感项（cookie / token / password / secret / key）必须留空 |
| `nodes` | ✅ | 节点数组；`type` 必须是受支持的节点类型 |
| `edges` | — | 连线；`sourceHandle` 决定走哪条出口 |
| `log` | — | 日志档位与关键字规则；缺省用默认 |

**校验**（导入时逐条执行，任一条失败即拒绝并点名原因）

1. 合法 JSON，体积 ≤ 1 MB；
2. `name` 非空且 ≤ 100 字符；
3. `nodes` 非空，每个节点 `id` 唯一、`type` 受支持，结构通过 `validateFlow`；
4. 每条边的 `source` / `target` 都存在；`sourceHandle` 与源节点出口匹配；
5. `vars` 中敏感项默认值为空或缺失（发现非空敏感默认值 → 清空后提示）；
6. URL 仅限 `http/https`，请求超时 10 秒。

## 3. 索引文件 v1（P0-5 规范）

```json
{
  "version": 1,
  "name": "社区索引（示例）",
  "updatedAt": "2026-11-15",
  "entries": [
    {
      "id": "demo-checkin",
      "name": "示例签到",
      "desc": "演示用的单步签到流程",
      "tags": ["签到", "入门"],
      "vars": [
        { "name": "cookie", "label": "登录 Cookie", "required": true, "sensitive": true },
        { "name": "ua", "label": "浏览器标识", "required": false, "sensitive": false }
      ],
      "nodes": 3,
      "sha256": "0f3c…（模板文件内容的 SHA-256，64 位十六进制）",
      "templateUrl": "https://example.com/templates/demo-checkin.json",
      "minApp": "0.5.0",
      "updatedAt": "2026-11-15",
      "source": "https://example.com/index.json"
    }
  ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `version` | ✅ | 协议版本，当前固定 `1` |
| `entries[]` | ✅ | 条目数组，≤ 500 条 |
| `entries[].id` | ✅ | 全局唯一标识（建议 `域名-用途` 或随机短串） |
| `entries[].name` / `desc` | ✅ / — | 展示用；`name` ≤ 100 字符 |
| `entries[].tags` | — | ≤ 8 个，用于筛选 |
| `entries[].vars[]` | ✅ | **必须显式声明**变量：`name` / `label` / `required` / `sensitive`；导入前据此生成变量清单 |
| `entries[].nodes` | ✅ | 节点**数量**（用于卡片展示"会做几步"），不是节点内容 |
| `entries[].sha256` | ✅ | 模板内容的 SHA-256（64 位十六进制）。**按规范化 JSON 计算**：对象键排序后序列化，数组保持原序——同一份内容换个键序不应改变哈希 |
| `entries[].templateUrl` | 二选一 | 模板文件地址；`http/https` |
| `entries[].template` | 二选一 | 直接内联完整模板（`{ name, desc, vars, varNames, nodes, edges, log, notify }`）。此时 `templateUrl` 可省略，但 `sha256` 必须对内联内容计算 |
| `entries[].minApp` | — | 兼容的最低版本；低于当前版本时提示"需要更新 CheckQ"，不阻止查看 |
| `entries[].updatedAt` / `source` | — / ✅ | 内容更新时间；来源地址（用于展示出处） |

**校验**

1. 索引 ≤ 1 MB，`version === 1`，`entries` 为数组且 ≤ 500 条；
2. 每条必填字段齐全；`id` 在索引内唯一（跨索引重复时按"另存"处理）；
3. `templateUrl` 为 `http/https`；内联模板同样走 §2 的全部校验；
4. 拉取模板后重算 SHA-256，与条目声明一致；不一致 → **拒绝导入并提示"内容与声明不符"**；
5. 未知字段忽略（便于后续扩展）；未知 `version` 拒绝并提示升级。

---

## 4. 获取与刷新

- 索引地址由用户填写（"关注"），保存在本机；**不内置任何官方索引地址**。
- 打开市场页时按需拉取，超时 10 秒；失败只影响该索引，不影响其它索引与本地模板。
- 刷新发现新条目 → 只提示"有 N 个新模板"，**不自动导入、不自动覆盖已有模板**。
- 索引被删除或失效 → 保留已导入模板，提示来源不可用。

---

## 5. 导入后发生什么

| 步骤 | 行为 |
|---|---|
| 1 | 校验通过后进入**预览**（节点链、变量表、来源、哈希、更新时间、是否含脚本节点） |
| 2 | 用户确认导入 → 生成模板，`source` 记录来源地址与哈希 |
| 3 | **敏感变量默认值强制清空**，界面标明"需要你填写" |
| 4 | 缺必填变量时在清单里标红，但**不阻止保存**（允许先存后填） |
| 5 | 从该模板创建任务时，**任务默认停用**，避免带着空凭据被调度 |
| 6 | 同一 `id` 重复导入 → 询问"覆盖 / 另存为" |

**含脚本节点的模板**：卡片与预览必须标注"含脚本"，首次运行前弹出一次确认（说明脚本在本机沙箱执行、沙箱无网络与文件能力）。导入阶段**绝不执行任何模板内代码**。

---

## 6. 安全与内容治理

- 框架只做协议与客户端；不托管、不审核内容、不提供下载镜像。
- 导入过程只做结构校验与哈希校验，不发起除"拉取索引/模板"之外的请求，不执行代码，不自动运行。
- 界面必须展示来源地址与哈希前 12 位；来源缺失的条目不允许导入。
- 模板中出现真实凭据（非空敏感默认值）→ 视为不合规内容，清空并提示，同时不进入"可分享"状态。
- 分发方的责任：内容合规由托管方承担；框架方只提供校验与提示。

---

## 7. 版本与兼容

- `version` 目前只有 `1`；字段一旦发布即冻结，新增字段必须可选且向后兼容。
- 模板文件新增节点类型时，旧版本客户端遇到未知 `type` 应**拒绝导入并列出类型名**，而不是静默丢弃。
- 本协议与实现同步的责任：`server/src/market.js`（解析 / 哈希 / 预览）与 `server/src/api.js`（`/api/market/*`）必须与本文档一起改；`docs/PRD.md` §5.5 记录产品验收，`server/test/v05.test.js`、`server/test/example-index.test.js` 是自动化护栏。
