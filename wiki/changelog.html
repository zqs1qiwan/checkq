0.6.2（2026-11-17）

品牌与登录体验

  • 正式标志与 favicon — 新增 CheckQ 标志：深青圆角徽章 + 白色勾 + 浅青 Q 尾点；补齐 SVG、ICO、16/32 PNG、180×180 apple-touch-icon，浏览器标签页、iOS 主屏与文档站统一使用同一图形。
  • 登录页重做 — 桌面为“品牌区 + 登录卡”两列，窄屏折叠为单列；品牌区给出“开源的可视化自动挂机、签到框架”与三条承诺，登录卡改为显式字段标签、更清晰的主按钮与底注。
  • 品牌组件共用 — 新增 Logo.jsx，顶栏、登录页、加载态、空状态使用同一徽章与字标；不再出现“Check Q”被 flex gap 拆开或各页面自行画勾。
  • 首页细节 — 顶栏品牌组合统一为 22px 徽章 + 字标；未筛选的空列表增加低对比度品牌水印，搜索无结果时不显示。
  • 文档与品牌资产 — 新增 docs/BRAND.md（名称、标志、色彩、留白、资产路径、界面用法）；README、GitHub Pages 文档站与社交预览补齐标志和 favicon；docs/assets/social-preview.png 可直接用于仓库 Social preview。

0.6.1（2026-11-17）

自动恢复探测（默认关闭）

  • 自动停用后的可选恢复 — 任务自动停用后，可按需开启“自动恢复探测”：按固定间隔静默重跑一次，成功才重新启用调度。默认关闭，升级不会让任何现有任务开始探测。
  • 风控约束 — 探测间隔最少 30 分钟、最多 5 次；探测失败不会再次自动停用，也不会立即重试；达到上限后停止，并写一条“自动恢复已停止”站内通知。
  • 探测静默 — 探测是真实运行，但不发任务通知、不写外部渠道；一次探测只执行一次，不沿用任务级重试，避免绕过“最多探测 N 次”的风控上限；运行抽屉显示“恢复探测”的尝试次数与结果。
  • 两处入口一致 — 任务详情与编辑器调度弹窗共用同一组恢复探测控件；自动停用提示会显示探测间隔、下次时间与已失败次数。

界面修复

  • 重试预览口径修正 — 失败重试的等待预览改为 equal jitter 的真实区间（约 50%–100%），不再显示固定 0.75 倍。
  • 调度弹窗校验 — 启用定时调度但 cron 为空时明确报错，不再出现“显示已启用但不会运行”的假状态。
  • 克隆配置完整 — 克隆任务不再丢失失败重试与恢复探测配置。
  • 暂停状态可见 — 任务列表的“已暂停”悬停提示带恢复探测信息；调度弹窗补上自动停用提示。
  • 运行触发可见 — 运行抽屉区分手动 / 调度 / 调试 / 恢复探测，探测记录一眼可辨。

清理

  • 新增 server/src/recovery.js 作为恢复配置与运行态的唯一规范化入口，避免前端、API、调度器各写一套边界。
  • 新增 web/src/components/RecoveryFields.jsx，两处调度 UI 共用，避免再次出现入口配置不一致。

0.6.0（2026-11-17）

稳定性与安全

  • AI Key 加密补全 — AI 助手的 API Key 与旧版单条 API Key 现在与任务凭据一样，落盘为 enc:v1: 密文；内存中解密使用，首次启动自动迁移旧明文。初始账号密码只打印一次，不再写入 meta.json。
  • 通知发送统一 — 12 类渠道收敛到唯一发送出口：统一 15 秒超时、并行发送、单渠道失败不再拖慢其他渠道；engine.js 的「通知」节点也复用同一套实现，Webhook 返回非 2xx 会如实判失败。
  • 通知失败可见 — 每次运行记录 notify: { total, ok, failed[] }；外部渠道全部失败时，站内另写一条「任务通知失败」。运行抽屉显示「通知：N/M 渠道成功」，悬停可看失败原因。
  • 全局并发上限 — 同任务继续串行，跨任务默认最多同时执行 4 个；可用 CHECKQ_MAX_CONCURRENCY 调整（1–16）。/api/system/stats 增加 maxConcurrency 与 globalWaiting，排期洪峰不再同时打满出口。

清理与一致性

  • 删除 api.js 与 engine.js 各一套的渠道发送代码，新增 notify.js/concurrency.js 单一职责模块。
  • 修复同任务队列的异常传染：上一轮异常结束后，后续排队任务仍能继续执行，不会永久卡住。
  • 修正架构文档里「五个 JSON 文件」等陈旧口径，补运行时开关与 run.notify 字段说明。

0.5.3（2026-11-16）

变更

  • 每日汇总独立成系统通知 — 汇总不再借用任何任务的通知渠道，也不再需要勾选「推送单位」。系统通知有独立的渠道列表（channels.json 加密存储，与任务凭据同一套 AES-256-GCM），站内通知内置且不可移除，外部渠道最多 10 条。停用、删除任务都不影响汇总。
  • 设置页改版 — 「通知与推送」拆成「界面提示」和「系统通知」：可设开关、发送时间、时区、空日是否发送，维护渠道，查看上次结果，并支持保存、测试发送、预览、立即发送。原「推送单位」整块移除，任务通知改在编辑器「更多 → 通知渠道」里配置。
  • 汇总内容按昨日统计 — 固定统计服务器本地时间的昨日 00:00–23:59；一天只发一次（按窗口日期记幂等），停机错过会在启动后补发一次并标注「（补发）」；空日默认不发。正文包含启用任务数、运行次数、成功率、最多 5 条失败与暂停任务，总长不超过 2000 字符。
  • 旧配置自动迁移 — 首次启动会把旧「推送单位」中第一个仍启用任务的渠道复制为系统渠道，并在设置页提示一次「汇总已从任务「X」独立」；旧 targetFlowIds 只读保留一版。
  • 外部渠道失败兜底 — 任一外部渠道失败时，站内会另写一条「汇总推送失败」，列出渠道数量与错误原因；汇总发送不阻塞调度，异常不会冒到定时任务之外。

0.5.2（2026-11-16）

修复

  • 任务停用后不再借它发每日汇总 — 定时汇总只向仍在启用的推送单位发送；所选单位全部停用时跳过本次推送。设置页会把已停用的推送单位标出来，避免"任务停了汇总还在来"。
  • 汇总不再顶着任务的名字 — 每日汇总的站内通知标题固定为「每日汇总」，不再沿用任务的通知渠道标题（此前会显示成某个任务的名字，看起来像任务还在发）；站内通知也不再挂到该任务名下。

0.5.1（2026-11-16）

这一版修的是三处日常使用里最硌手的地方：图标不成套、分组只能手打、失败一直刷。

修复

  • 连续失败自动停用 — 调度触发的运行在退避重试用尽仍失败时，任务自动停用调度，并在状态列显示「已暂停」、记录停用原因；行内结论与通知追加「（已自动停用调度）」。手动运行与调试运行不受影响；在任务详情勾选「启用定时调度」即恢复并清掉暂停标记。
  • 分组可以从列表选 — 任务详情与批量「分组…」里的分组输入改成带下拉的分组选择器：列出实例里已有的分组，点击即填入；当前分组高亮，可「清空（不分组）」，也能继续手输新建。此前是原生 datalist，在弹窗里没有可见的展开按钮，编辑器路径还拿不到分组列表。
  • 图标统一 — 下拉箭头、行内「更多」、弹窗关闭全部换成 SVG（▾ / ⋯ / ✕ 文本字形退场）；主题 / 文档 / 帮助图标收窄到同一光学尺寸；编辑器画布控件与小地图补上边框、圆角和统一按钮尺寸。

改进

  • 节点的「失败未接」角标与「循环体已折叠」提示不再被节点边框裁掉。

0.5.0（2026-11-16）

这一版的共同主题是可信：流程图不再骗人、失败能说清原因、改了参数就地重跑、空实例也能先跑通一次。

新增

  • 结构可见 — 画布上每个出口都能看见：未接线的出口是空心点，http 的失败出口没接时节点带「失败未接」角标、连线走虚线；foreach 的循环体有虚线容器和「循环 · N 步」标签；新增「大纲」视图按执行顺序列出步骤（含循环内缩进、断头出口、未接入步骤）；保存后若结构有隐患，弹一次「结构检查」清单，逐条可定位。只提示，不改执行语义。
  • 大图默认折叠循环体 — 流程到 60 个节点，循环体默认收起（画布只留遍历节点，标签写「循环 · N 步 · 已折叠」）；点容器上的「展开」逐个放开，数据与保存内容不受影响。
  • 新建入口四分支 — 顶栏「+ 新建」展开四个并列选项：空白流程 / 从模板 / 导入 HAR·JSON / 导入 cURL；「更多」只留进阶动作（快速组装等）。
  • 可解释失败 — 运行失败时，日志坞顶部先给一张诊断卡：一句话原因（如「登录凭据已失效」）、判断依据（证据）、以及四个可点的下一步（看这一步的响应 / 改变量 / 调整断言 / 复制为排障摘要）。九条规则覆盖缺变量、凭据、风控、断言、网络、5xx、4xx、引擎、未知。
  • 演练场 — 新实例空首页有「先演练一遍」：内置本机演示站点（资料 / 签到 / 列表），零站点零凭据，30 秒跑通一次成功运行；跑通后在编辑器把标记换成「换成我的站点」即可改成自己的任务。演示数据只在本机内存、1 小时后丢弃。CHECKQ_DEMO=0 可关。
  • 修改即重跑 — 任务行主操作改成「运行 ▾」：立即运行 / 带改变量运行 / 只看日志 / 调试运行。「带改变量运行」直接列出该任务的变量（敏感值遮蔽），改完就保存并运行，不再为改一个 cookie 进画布。同一任务已在运行时重复点击不会重复提交。
  • 模板市场 — 首页新增「市场」：填索引地址即可浏览、订阅；卡片显示步数、变量数、来源与哈希前 12 位；导入前必预览（变量清单、必填标注、含脚本提示）；服务端会重算哈希，对不上直接拒绝；同一模板重复导入会问你「覆盖」还是「另存副本」。索引协议见 docs/TEMPLATE-MARKET.md，随包有示例 docs/template-index.example.json。
  • 本机统计 — 设置新增「统计」页签：近 N 天运行量、成功率、首次跑通耗时（中位 / p90）、失败后修复耗时、模板复用数、每日分布。全部由本机数据现算，不上传、不随备份导出，空库显示 0。

改进

  • 编辑器的撤销 / 重做 / 复制粘贴 / 运行三件事抽成独立 hooks，画布组件变小、行为不变。
  • 首页任务行对只读角色隐藏写入口；空状态永远带一个动作。

修复

  • 市场预览里「含脚本」标记此前取不到（字段位置不一致），现在预览与导入都会给出。
  • 度量里首跑耗时在样本为 0 时不再出现 NaN。

0.3.17（2026-11-13）

新增

  • 任务分组 / 折叠 — 任务可设置分组；列表按组折叠，组头显示任务数、启用数、今日成功 / 失败 / 成功率、下次调度；大分组默认收起，搜索 / 筛选时自动展开；支持批量勾选后「分组…」一次归入。
  • 单次运行导出 HAR — 运行抽屉「导出 HAR」，可直接拖进浏览器 DevTools 复现；敏感值（cookie / token / 密码）自动替换为 ***。
  • 编辑器效率 — 撤销 / 重做（Ctrl+Z / Ctrl+Y）、节点复制粘贴（Ctrl+C / Ctrl+V）、按连线层级「整理」布局、MiniMap 缩略图；点击日志步骤 ↔ 画布节点双向定位。
  • 失败自动重试 — 任务级退避重试（默认最多 3 次、指数退避 5 秒起、随机抖动），跑满次数仍失败才判定任务失败；每次尝试与等待时长写进运行记录、日志与通知。

改进

  • 弹窗 / 菜单改用浏览器原生能力：焦点管理、Esc 关闭、背景 inert、顶层渲染更稳定。
  • 窄屏顶栏只保留「品牌 / 新建 / 更多 / 设置」，主题、通知、文档、身份收进「更多」；工具条分组不再把按钮挤到换行。
  • 列表表头吸顶、数字等宽对齐；设置页分区更清晰。

修复

  • 删除任务的确认弹窗在操作完成后不再卡在屏幕上；取消 / Esc / ✕ 均可关闭。
  • 提示条 5 秒后自动消失，不再需要手动点掉。
  • 通知渠道「保存」后弹窗自动关闭；「测试发送」保持在原弹窗内查看结果。
  • 部分场景下设置页打不开的问题；流程没有日志节点时运行记录不再显示为空。
