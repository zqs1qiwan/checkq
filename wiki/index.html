CheckQ 文档

CheckQ 是一个可视化 HTTP 自动化流程引擎：把每天要做的签到、监控、定时请求，做成可编辑、可复用、可被外部程序驱动的流程。

本站只讲框架能力与用法，不含任何具体签到脚本、站点规则、模板内容或账号信息。

核心能力#

能力说明
积木式流程HTTP / 条件 / 赋值 / 提取 / 延迟 / 日志 / 通知 / 脚本 / 遍历 节点，拖拽连线即成流程
点选生成逻辑运行后点响应里的任意值 → 一键生成提取 / 断言 / 关键字 / 通知 节点
导入浏览器 HAR、cURL 命令、JSON 模板导入，自动生成流程图
调度每个任务独立 cron + 时区 + 抖动；支持手动运行与「调试运行」；失败按退避策略自动重试，跑满次数才判定最终失败
日志默认只输出人话日志，可开调试模式看每步请求与响应；运行记录含逐次尝试与等待时长
通知12 种渠道：站内通知、Webhook、Bark、Telegram、Server酱、PushPlus、钉钉、企业微信、飞书、Gotify、ntfy、邮件 SMTP
模板调试好的流程存为模板，一份模板派生多份任务；模板一改，派生任务的流程图与日志配置立刻跟随，零同步操作；通知渠道在创建时复制，之后各自维护
账号安全多用户 + 角色、TOTP 两步验证、会话吊销、凭据静态加密、API Key 作用域与 IP 名单
开放接口REST（OpenAPI 3.1）+ MCP（20 个工具），外部 Agent 可直接操作
任务分组任务可归属分组，列表按组折叠；组头显示任务数、启用数、今日成功/失败/成功率、下次调度

本站讲什么#

  • 框架能力：流程引擎、节点与变量、调度与重试、日志与通知、模板联动、账号安全、开放接口。
  • 操作步骤：从建任务到部署备份、排障速查。
  • 参考手册：REST API、MCP 工具、安全说明、Agent 接入。
